# 弹珠漫游 · Marble Drift

一个纯浏览器运行的解压弹珠小游戏。所有资源随项目保存，不依赖在线 CDN。

## 试玩

直接打开 `dist/index.html`，或者安装 Node.js 后在本目录运行 `npm start`，访问打印的本地地址。运行 `npm test` 验证核心规则和物理行为。

## 操作与规则

- 点按发射一颗；长按发射键或空格键连续发射。发射口和五个倍率门自动左右移动。
- 参考视频布局：上方三个错落门，下方两个并排门，底部斜坡汇入中央出口。
- 默认倍率依次为 ×5、×5、×20、×3、×3。每颗球对每个门仅触发一次，子球继承已穿过的门；倍率表示包含原球在内的总数。
- 每颗球从底部落出得一分；默认每 100 分额外获得一颗待发弹珠；跨过多个奖励阈值时全部发放。
- 默认初始 30 颗。待发、场内和排队弹珠全为零时自动结算，最后一批落球仍可获得奖励。
- 每次穿过倍率门、每颗落袋各积攒 1 点狂热能量。默认积满 100 点后自动进入 **5 秒狂热**：弹珠无限、发射加速、倍率门加宽、弹珠变金色。期间发射不消耗库存，即使库存为零也能发射；仍遵守同屏物理弹珠数量上限。
- 狂热期间不蓄能、不延长时间，结束后从零重新积攒；暂停游戏、打开设置或切到后台时，狂热倒计时同步暂停。狂热结束前不会提前结算。
- 穿门增加扇形爆珠、光环和门体回弹反馈；连锁提示显示同一条增殖路径的叠乘结果，例如二连 `1 → 100 颗`，音效音调随连锁层数升高。
- 设置中可调整五个门的倍率（1–20）、初始弹珠（1–1000）、奖励分数（1–10000）、狂热能量门槛（1–10000）；保存后开始新一局。旧设置会自动补上默认狂热门槛，其他设置保留。
- 场内弹珠上限也可在设置中调整（100–2000，默认 400），游玩时显示当前数量与上限。旧设置自动补上 400，保存设置后开始新一局。

## 性能与物理

采用 Matter.js 0.20.0 二维刚体物理引擎：重力、球球碰撞、边界回弹、漏斗斜坡。120 Hz 固定时间步、速度限制、厚边界与非重叠生成位置共同控制高速穿透。

同屏真实碰撞弹珠数量按设置上限执行。超额增殖按“来源倍率门 + 已触发门集合”压缩排队，不丢球、不提前加分、不用加权球代替实体球。高倍率组合可能形成很长的队列；可暂停或重开。

长按发射按物理时间步调度：出球成功后才扣库存和推进连发间隔，暂时拥堵会自动重试。增殖队列会为发射预留空间；点按时被挡住的一发会等待出球，松手不再自动连发。暂停会取消尚未出球的发射请求。
